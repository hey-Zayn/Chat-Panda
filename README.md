ChatPanda - Immersive 3D Marketing Website
A modern, high-performance marketing website built to showcase the ChatPanda brand. This project demonstrates advanced front-end techniques to create a visually stunning and engaging user experience through seamless animations and interactive 3D elements.

🚀 Live Demo
chat-panda.vercel.app

✨ Features
Immersive Animations: Smooth, scroll-triggered animations and transitions powered by GSAP.

Interactive 3D Elements: Engaging 3D visuals integrated using Three.js and Spline.

High Performance: Built with Next.js for optimal speed, SEO, and server-side rendering.

Fully Responsive: Designed with Tailwind CSS to ensure a flawless experience on all devices.

Visual Storytelling: Motion design and modern UI principles guide the user and reinforce the brand message.

🛠️ Tech Stack
Framework: Next.js

Styling: Tailwind CSS

Animations: GSAP

3D Graphics: Three.js, Spline

Deployment: Vercel
